AIReviewSystem V1.009 - 使用说明（单机/局域网版）
====================================================

【软件简介】
AI 交易复盘系统：录入交易、多周期截图识别、AI 交易复盘分析、
交易系统/策略管理、阶段性 AI 复盘、A股每日复盘。多用户，数据互相隔离。

【A股每日复盘（V1.009）】
- 一键采集当日盘面：8 大指数、涨跌分布、涨停/炸板/跌停梯队、
  连板高度、两市成交额与量能、概念板块温度榜、人气热度榜、
  龙虎榜游资、严重异动提醒，并生成 AI 盘面点评
- 支持 60 个交易日内任意历史日完整回溯（历史日以「重建数据」刷新）
- 每个指标旁「?」可看定义、计算公式与数据来源

【手续费计入盈亏（V1.006）】
- 每笔交易盈亏按净额计算：统计盈亏 = 盈亏金额(毛) - 手续费
- 收益率/胜率/盈亏比/期初期末资金/回撤/夏普等指标全部按净盈亏口径
- 录入时"盈亏金额"填不含手续费的毛盈亏，"手续费"单独填写，系统自动扣除

【多币种资金（V1.006.3）】
- 账户资金流水支持人民币(CNY)与美元(USD)双币种，USDT 按 1:1 并入美元
- 数字货币交易：手数即 USDT 持仓规模（如开仓 5 万 USDT 填 50000，
  占用资金 = 50000 USDT，盈亏计入美元币种）
- A股/商品期货盈亏计入人民币，数字货币盈亏计入美元
- 阶段复盘期初/期末资金按币种分别展示（人民币 ¥ / 美元 $）

【商品期货资金占用（V1.007）】
- 资金占用 = 开仓价 × 手数 × 合约乘数 × 保证金率
- 内置 87 个品种合约乘数表（含名称容错匹配），支持管理员在
  【期货参数】页补录/修改品种乘数与保证金率
- 保证金率每日自动从东方财富同步，也可手动覆盖
  （优先级：合约级覆盖 > 品种级同步/手动 > 内置默认 10%）
- 交易保存时固化"品种/乘数/保证金率"快照，历史收益率不受日后
  保证金率变化影响
- 未识别的品种代码/名称：占用资金留空，录入时强制手动填写，
  避免收益率分母失真

【首次使用】
1. 双击「启动.bat」（推荐用这个启动）：它会先检查文件是否解压完整，
   有问题会停下来用中英双语提示，不会一闪而过；一切正常时自动打开网页
   http://localhost:8000
   （也可以直接双击 AIReviewSystem.exe，效果一样，只是出错时提示较少）
2. 点"注册"，第一个注册的用户自动成为【管理员】
3. 其他用户可自行注册（普通用户）

【配置 AI 分析（可选但强烈建议）】
本软件兼容所有"OpenAI 协议"的大模型服务（DeepSeek、通义千问、
Kimi、智谱 GLM 等），推荐在软件界面直接配置，无需改文件：

1. 登录后点右上角"账号"→【API 设置】
2. 填入三项后保存，AI 分析下次调用即生效：
   - API Key：到对应服务商平台注册获取
   - 接口地址（Base URL）：切换服务商时填写，留空用默认
   - 模型名称：留空用默认

常用服务配置示例：
【DeepSeek】    Key 到 https://platform.deepseek.com 注册获取
   接口地址 https://api.deepseek.com
   模型 deepseek-chat
【通义千问】    Key 到阿里云百炼(DashScope)平台获取，接口用"兼容模式"
   接口地址 https://dashscope.aliyuncs.com/compatible-mode/v1
   模型 qwen-plus（也可 qwen-max / qwen-turbo，以百炼平台为准）
【Kimi】        Key 到 https://platform.moonshot.cn 注册获取
   接口地址 https://api.moonshot.cn/v1
   模型 moonshot-v1-8k

进阶说明：
- 出厂默认值（DeepSeek）已内置在程序内部，本目录无需也不存在
  .env 文件；界面未配置时用内置默认，界面配置后以界面为准
  （清空界面项 = 恢复内置默认）。
- 不配置时交易录入/统计等功能可用，AI 分析会提示未配置。

【手机/其他电脑访问】
- 同一 WiFi 下，手机浏览器打开 exe 窗口里显示的地址
  （如 http://192.168.1.5:8000）
- 打不开时，Windows 防火墙弹窗请点"允许访问"

【★ 双击没反应 / 黑窗口一闪就没了（闪退）怎么办（V1.009.2）】

从 V1.009.2 起，程序不会再把错误"悄悄吞掉"：
  · 启动失败时会把原因留在窗口里，按回车才关闭；
  · 同时把完整日志写到本目录「startup_log.txt」；
  · 双击「诊断.bat」可生成「diagnose_report.txt」诊断报告。

遇到闪退，请按下面顺序处理：

第 1 步：改用「启动.bat」再试一次
  它会先检查文件是否齐全，缺文件时直接告诉你缺哪个，不会一闪而过。

第 2 步：确认是"完整解压"
  必须用压缩软件「解压到当前文件夹」，不能只把 exe 拖出来，
  也不能在压缩包里直接双击运行。程序依赖同目录的 _internal 文件夹
  与其中的前端资源，少一个文件就会启动失败。
  解压后目录里应当能看到这 4 项：
    AIReviewSystem.exe、_internal、app.db、uploads
  若反复解压仍缺文件，先临时关闭杀毒软件（360 / 电脑管家 /
  Windows Defender）再加白名单，然后重新解压。

第 3 步：双击「诊断.bat」
  它会做完整检查并生成「diagnose_report.txt」，
  把这个文件发回给作者即可定位问题（日志也可一并发送 startup_log.txt）。

常见原因对照：
- 提示「端口 8000 已被其他程序占用」：别的软件占着 8000。
  按窗口提示执行 netstat -ano 配合 findstr :8000 查到 PID，
  在「任务管理器 → 详细信息」结束该进程；
  或直接双击「换个端口启动.bat」用 8080 端口启动
  （注意：不要同时用两个端口开同一套程序，会写坏数据库）。
- 提示「Incomplete files: _internal folder is missing」/
  「缺少 _internal 依赖文件夹」：解压不完整，见第 2 步。
- 提示「数据库无法读写」：目录只读、被占用或被安全软件拦截。
  把整个文件夹放到 D 盘或桌面（不要放 Program Files），
  并检查杀毒软件的拦截记录。
- 提示「已在运行」：旧服务还开着，浏览器会自动打开它；
  想彻底停止请关闭旧的黑色窗口，或双击「停止服务.bat」。
- 窗口没有任何提示就消失：双击「诊断.bat」看报告，
  多半是杀毒软件（360 / 电脑管家 / Defender）拦截了 exe，
  加白名单后重试。

【忘记密码】
1. 关闭正在运行的程序
2. 双击本目录下"重置密码.bat"
3. 输入用户名和新密码，完成后再启动

【数据备份】
- 网页右上角"备份数据"按钮下载完整备份
- 或复制 app.db 和 uploads 文件夹（先停止服务）

【迁移/换电脑】
- 整个文件夹拷到任何 Windows 电脑，双击 exe 即可，无需安装
  （务必连 _internal 与 uploads 一起拷贝，只拷 exe 无法运行）
- 用户和数据都在 app.db + uploads 里

【截图清理】
- 上传错图/未关联交易的截图会占用空间
- 交易记录页右上角"清理无用截图"可一键清理

【注意】
- 启动提示 8000 端口被占用 = 旧服务没关干净，先关闭旧窗口；
  排障文件：startup_log.txt（日志）、diagnose_report.txt（诊断报告）
- 单机离线使用：不开浏览器之外的任何联网需求（AI 分析需联网）
