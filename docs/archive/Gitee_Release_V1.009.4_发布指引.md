## 一、情绪指标去掉「双口径」斜杠，只展示剔 ST 单值

**问题**：情绪指标卡上的涨停/跌停/炸板家数此前显示成 `55/57` 这种形式（**主值 / 含 ST 值**）。本意是"两个口径都给你"，实际看久了很费眼睛 —— 用户要的就是**一个数**：**剔除 ST、\*ST 之后的家数**。

**改动**：

- 三个卡片（涨停家数 / 跌停家数 / 炸板家数）的**斜杠后缀整块删除**，只留主值
- 指标标题由「涨停（剔ST）」这类带口径说明的写法简化为**朴素表述**：「涨停家数 / 跌停家数 / 炸板家数」
- **页面上所有情绪类指标一律走剔 ST 主口径**（`count` / `limit_up` / `limit_down` / `broken`）
- 含 ST 计数（`count_inc_st`）**后端继续保留**，供对账东财首页/APP 用；但**不再出现在界面上任何位置**
- 悬浮备注（「?」TIP）同步改写，明确写「**已剔除 ST、\*ST**」

**2026-09-14 实测读数**（截图自证）：

| 指标 | 显示值 |
|---|---|
| 涨停家数 | 55 |
| 跌停家数 | 16 |
| 最高连板 | 4 板 |
| 炸板家数 | 30 |
| 炸板率 | 35.29% |

页面渲染结果**无任何斜杠双口径**。

> **顺带修掉一处误导文案**：涨跌家数分布卡的 `title` 原本写「涨跌家数分布（剔除ST与涨跌停口径见说明）」，会让人以为**这张表每一档都剔了 ST**。实际上该表各档是**含 ST 的全市场区间统计**，只有「其中涨停 / 其中跌停」两行是剔 ST 口径。标题已简化为「涨跌家数分布」，避免口径误读。

## 二、新增：点击股票名称 → 弹出日线图 + EMA20

**需求原话**：*「能否在连板梯队、涨停跌停炸板个股、股票热门榜这些展示个股的地方都有一个新功能，就是点击股票名称，可以弹出一个窗口，展示这只股票的日线图和 ema20 均线」*

**能实现，本版已全部接线。**

### 2.1 可点击范围（6 类 · 12 处）

| 模块 | 接线点 |
|---|---|
| 连板梯队 | 梯队标签里的个股名 |
| 涨停 / 跌停 / 炸板 / 昨日涨停股今日表现 | 4 张明细表的名称列（ST 标签保留） |
| 主线题材与周期阶段 | 板块角色分层（龙头 / 中军 / 跟风 / 补涨）里的个股 |
| 严重异动提醒 | 个股名 |
| 游资动向（龙虎榜席位） | 席位关联个股标签 |
| 股票热度榜 | 个股列 |

交互上做了两个讲究：

- 股票名渲染为**蓝色 + 虚线下划线**（一眼看出可点，而不是靠鼠标悬停才发现）
- 点击时 `stopPropagation()` —— **不会误触发表格行展开**（个股表行本身是可展开的）

### 2.2 弹窗内容

- **ECharts 蜡烛图**，遵循 A 股习惯**红阳绿阴**
- **橙色 EMA20 折线**叠加
- **dataZoom**：默认只展示最近约 **130 根**，滑块可拖回更早（既保证近期形态看得清，又不丢长周期视野）
- **60 / 120 / 250 日**三档切换
- 头部显示：股票名称 + 代码 + **最新收盘 + 涨跌幅 + EMA20 值 + 日期**
- 脚注说明：数据源、EMA20 种子口径、红阳绿阴、默认展示根数

### 2.3 数据源实现：为什么必须「多源择优」

新增后端接口 `GET /api/daily-reviews/stock-kline?code=&days=`，源顺序 **腾讯 qfq 日K → 新浪日K → 东财 push2his**。

**关键设计**：不是「第一个非空就用」，而是**先看有没有源给够了请求的根数；都不够，才取根数最多的那个**。

原因是踩过一个实打实的坑 —— 「第一个非空即用」会被**残缺非空**结果短路：

> 腾讯对**多数北交所票只返回 1 根日线**（不是空，是有 1 根）。按"第一个非空即用"，这个 1 根的结果会**直接短路掉真正完整的新浪源**，最后弹窗里只画得出一根 K 线。

**实测数据源可用性**：

| 股票 | 可用源 | 根数 |
|---|---|---|
| `600519` 贵州茅台 | 腾讯 | 120 ✓ |
| `300430`（创业板） | 腾讯 | 120 ✓（pct +20.0 与涨停吻合） |
| `920819`（北交所） | **新浪**（腾讯只给 1 根） | 120 ✓ |
| `999999`（非法代码） | — | 返回 `available:false` + note，**不抛错** |

### 2.4 顺带修复：北交所代码前缀 bug

**根因**：`920xxx` **也是 9 开头**，被「9 开头 = 沪市」的分支**先吃掉**了：

- `_em_secid_of_stock("920819")` 误返回 `"1.920819"`（应为 `"0.920819"`）
- `_tencent_code_of_stock("920819")` 误返回 `"sh920819"`（应为 `"bj920819"`）

**实测**：`sh920819` **取不到任何数据**，`bj920819` 正常。

**修法**：新增 `_is_bj_code()`（`43 / 83 / 87 / 88 / 920` 开头，覆盖新三板转板与 2023 起新号段），并**前置于 9 判断**。

### 2.5 EMA20 的算法口径

**首值取前 n 项的算术均值作种子**（与通达信 / 东方财富的显示口径一致），而非用第一个值直接起算 —— 后者会让开头一段系统性偏离。

不足 20 根时对应位置返回 `None`：图上的折线段**从第 20 根 K 线才出现**，而不是拿不足长度的样本硬算出一个失真的开头。若整只票取到不足 20 根，脚注会直接说明「EMA20 无法计算」。

### 2.6 性能

同一只股票 **10 分钟内存缓存**（弹窗会反复开关，不做缓存会重复联网）。缓存条数有上限，长期运行不膨胀。

## 三、「近期情绪趋势」图下移，理顺阅读动线

**问题**：趋势图原先放在页面顶部（「我的复盘」与「指数表现」之间）。设计初衷是"让**变化方向**先于单日数值出现"，但实际用起来顺序反了 —— **看变化之前，得先看到当日数值**才顺。

**改动**：整张「近期情绪趋势」卡片（含第二行的主线题材小图）**下移**到「涨跌家数分布 + 连板梯队」那一行之后、「概念板块情绪周期」之前。

**改动后的卡片顺序**（已用 DOM 顺序 dump 核对）：

```
我的复盘 → 指数表现 → 情绪指标 → 涨跌家数分布 → 连板梯队
  → 近期情绪趋势  ← 移到这里
  → 概念板块情绪周期 → 严重异动提醒 → 游资动向 → 股票热度榜
```

动线变成：**先看当日家数结构（分布 + 梯队）→ 再看这几天的方向变化 → 再下钻板块与个股**。

## 四、升级说明

- **覆盖升级**：用新包解压后覆盖程序目录即可，**数据库自动兼容**（不新增表、不删表、无需手工迁移）
- **无需重建历史数据**：本版三项改动全部是**展示层与新增接口**，不改动任何既有指标的计算口径与存量缓存结构
- 本版对历史数据**零改写** —— 情绪指标只是不再显示斜杠后缀，底层数据与 V1.009.3 完全一致

## 五、已知取舍

- **个股日线走实时联网**，不是本地缓存。若某只股票三个源都取不到（例如退市/长期停牌/新代码），弹窗显示「取不到数据」并给出原因，**不会阻塞页面**
- **北交所日线只有新浪源稳定可用**（腾讯对多数北交所票只给 1 根），已在取数逻辑里自动处理
- **历史重建序列与实时口径仍有约 15% 的差异**（V1.009.0 起的既定取舍，东财池只能回溯约 15 个交易日）；趋势图会标注数据来源
- **当日的榜单类数据（人气热度榜等）**需要实时抓取，历史日只能靠本地缓存回溯
