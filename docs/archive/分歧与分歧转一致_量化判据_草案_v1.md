## 〇、先厘清语义（这是判据分歧的根源）

| 概念 | 用户定义 | 本质 |
|---|---|---|
| **分歧** | 获利盘涌出，看多的人继续涌入，形成的多空分歧 | **买卖双方均放量** —— 不是「弱」，是「强分歧」 |
| **分歧转一致** | 分歧之后再次一致性加强 | 分歧的**多方胜出**出口 |
| **退潮** | 龙头 A 杀、跌停扩散、涨停减少、炸板进一步增多 | 分歧的**空方胜出**出口 |

**关键推论**：分歧**不是**判断「板块变差了」。它是「接力资金与获利盘在高位换手」。
因此分歧的判据必须**同时**捕捉「获利了结」（龙头断板/炸板）**和**「资金承接」（新龙头顶上/涨停未枯竭）——
只抓前者会把「高潮后的正常换手」误判成退潮。

## 一、分歧的判据（当日可判，硬信号）

分两组。**A 组是「卖出侧」，B 组是「买入侧」**。分歧 = A 组有信号 **且** B 组未崩（否则是退潮）。

### A 组：卖出侧（获利盘涌出）

| # | 信号 | 计算式 | 数据源 | 现状 |
|---|---|---|---|---|
| A1 | **龙头断板** | 昨日最高板那支票今日未涨停 | 涨停池 + `lbc` | ⚠️ **当前实现没有这条** |
| A2 | **炸板率跃升** | `zb_r ≥ 自身近 20 日均值 + Δ` | `zb_r`（已有） | 有，但 Δ=0.25 偏严 |
| A3 | **断板面** | 昨日涨停股今日未涨停的家数 ≥ N | 涨停池跨日集合 | ⚠️ **现口径漏掉首板断板** |
| A4 | **晋级率骤降** | `promo` 环比降幅 ≥ 50% | `promo`（已有） | 有，未参与判定 |
| A5 | **接力溢价转负** | `prem < 0`（昨日涨停股今日平均涨幅） | `prem`（已有） | 有，未参与判定 |
| A6 | 龙头高位放量 | 龙头当日成交额 / 近 5 日均额 ≥ 2 | 个股日线 `amount` | 可算，未用 |

### B 组：买入侧（资金仍在承接）

| # | 信号 | 计算式 | 数据源 |
|---|---|---|---|
| B1 | **新龙头接棒** | 今日最高板 > 昨日最高板，且该票不是昨日的最高板那只 | 涨停池 `lbc` |
| B2 | 涨停家数未枯竭 | `zt ≥ 昨日 zt - 1`（允许小幅回落） | `zt`（已有） |
| B3 | 中军仍强 | 市值前 K 只成分股中位涨幅 ≥ 1% | `mktcap` + 日线 |
| B4 | 后排未熄火 | 市值后 50% 组上涨占比 ≥ 50% | 同上 |

### 判定

```
分歧 = (A1 或 A2 或 A3 或 A4 或 A5 中 ≥2 项)
       且 (B1 或 B2 为真)          ← 有承接 → 不是退潮
退潮 = (A 组 ≥2 项) 且 (B1、B2 均假) 且 (跌停家数环比增加 或 prem < -2%)
```

**为什么要求 A 组 ≥2 项**：单条信号噪声大（实测 A2 一条就能在任意一天触发）。
要求两条同时成立，是把「分歧」从「随机的炸板日」里择出来。

## 二、分歧转一致的判据（次日确认）

用户的语义是「分歧之后再次一致性加强」，所以这是**跨日**判定：

| # | 信号 | 计算式 |
|---|---|---|
| R1 | **新龙头确立** | 今日最高板 ≥ 昨日最高板，且该票在昨日分歧日已涨停（承接而非凭空） |
| R2 | 涨停家数回升 | `zt > 昨日 zt` |
| R3 | 炸板率回落 | `zb_r < 昨日 zb_r` |
| R4 | 接力溢价回正 | `prem > 0` |
| R5 | 老龙头未深杀 | 昨日断板的龙头今日涨幅 ≥ −3%（排除 A 杀） |

```
分歧转一致 = R1 且 (R2 或 R4) 且 R5
分歧转退潮 = 非 R1 且 (R2 假) 且 (R4 假)
```

**R1 是核心**。用户原话「老龙头有分歧迹象，但是有新龙头顶上」——**「有新龙头顶上」就是转一致的判据本身**。

## 三、三出口路由图

```
                    ┌─ B1/B2 有承接 ──► 【分歧】─┬─ R1+R2/R4 ──► 发酵 / 高潮（分歧转一致）
   昨日 发酵/高潮 ──┤                            ├─ 非R1 且无回补 ─► 退潮
                    └─ 无承接       ──► 退潮      └─ R1 但涨停未回升 ─► 分歧延续（再观察）
```

| 日期 | A 组 | B 组 | 结论 |
|---|---|---|---|
| 09-14 | A2（炸板率）、A5（接力溢价） | B1 假（高度未升）、B2 真（涨停 8>7） | **高潮**（4 层里 3 层命中） |

## 五、与当前 v1.0.9.7 实现的差异

| 项 | 现状 | 本草案 |
|---|---|---|
| 龙头断板 | **无此判据** | A1 硬信号 |
| 断板数 `brk_n` | 只数**连板**断板（`prev_lb` 仅收 `lbc≥2`） | 改用**昨日全部涨停股** |
| 炸板率阈值 | `zb_r ≥ 均值 + 0.25`（09-15 实测 0.375 vs 需 0.5683） | 见 A2，Δ 需重标定 |
| 分歧判定 | 单条 `is_split` 任一为真即分歧 | **A 组 ≥2 项 且 B 组有承接** |
| 分歧转一致 | 有转移扇出（实测 57→高潮 / 183→发酵），但**无显式判据** | R1 为核心 |
| 涨停家数 | ⚠️ **最新交易日系统性少计**（另见缺陷记录） | 须先修数据层 |
